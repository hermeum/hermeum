# What is Hermeum

Hermeum is a platform for creating **tailored AI agents** for your team.
Every agent is built on top of the open-source [Hermes agent](https://hermes-agent.nousresearch.com/docs), so it inherits
powerful built-in capabilities, while Hermeum gives you a simple way to shape,
run, and manage it.

## Build an agent in your own words

You do not need to be a Hermes expert, or even a developer, to get started.
Describe what you want your agent to do, and Hermeum turns that into a working
agent you can chat with, deploy, and iterate on.

## What an agent can do

An agent can be connected to the tools and platforms your team already uses:

- answer questions, research topics, and browse the web
- chat through Slack, Discord, Microsoft Teams, or a custom webhook
- run tasks on a schedule
- expose an OpenAI-compatible API for other apps to use

## Shape it to your team

Every agent has a **soul** — a short description of its personality and purpose —
plus configuration for models, skills, environment variables, and integrations.
You can start from a template, or describe your agent in natural language and
let Hermeum generate the configuration for you.
